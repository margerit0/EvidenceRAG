# 调查工作台演示

本指南使用仓库内的**原创合成数据**，展示完整调查、需要补充信息、证据不足三条路径。
默认模式不调用模型，不需要 Python、后端、密钥、语料、索引或本地研究产物。
安装依赖需要访问 npm；安装与构建完成后，演示只读取本地静态资源。

## 启动生产构建预览

需要 Node.js 22.12+ 和 npm。在仓库根目录执行：

```powershell
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend run preview -- --port 4173 --strictPort
```

打开 [本地演示](http://127.0.0.1:4173/workbench/)。预览进程在当前终端运行，结束时按
`Ctrl+C`。端口被占用时命令会失败；可改用空闲端口并调整浏览器地址。修改前端源码后，
先重新执行 `build` 再预览；需要边改边看时使用 [开发服务](frontend.md#本地启动)。

确认顶部运行模式为“模拟演示”，旁边显示“原创合成数据 · 无 API 调用”。三条路径由
输入框上方的“演示场景”选择，切换后会填入对应问题。可以点击“新调查”清空当前展示，
然后选择下一场景；最近运行仅保存在页面内存，刷新即清空。

`preview` 用于检查本地生产构建，不是公网部署方案。此指南不需要启动 FastAPI；
“连接服务”模式及 DeepSeek / GLM 的服务端配置另见
[选择调查模型](frontend.md#选择调查模型)。模型入口仅在已连接且服务提供模型选项时显示。

## 三条演示路径

| 演示场景 | 默认问题 | 完成后应看到 |
| --- | --- | --- |
| 完整调查 | 示例集群升级前，需要检查哪些配置与回退条件？ | “已生成答案”；两段答案分别带引用，时间线有两次搜索和两次读取。 |
| 需要补充信息 | 可以直接升级我的示例集群吗？ | “需要补充信息”；追问当前版本和目标版本，不显示答案或引用，不执行搜索和读取。 |
| 证据不足 | 示例文档是否承诺升级过程完全没有停机？ | “证据不足”；提示现有文档不足以支持结论，不显示带引用答案，仍可查看已经读取的证据。 |

### 完整调查

1. 选择“完整调查”，点击“运行演示”，观察执行图和逐次调用时间线。
2. 出现“已生成答案”后，点击答案中的引用 `2`，右侧应显示“升级演练 / 回退条件”，
   正文标注“原创合成演示文档”。桌面可点击“展开阅读”；窄屏直接打开阅读层。
3. 点击时间线中的第一次“搜索文档”，检查器应显示“搜索文档 · 第 1 次”。使用
   “下一次同类调用”切到第 2 次，图与检查器同步；这不会重新执行调查。

引用可追溯只表示能对照本次证据，不能据此认定结论已经通过独立质量验收。

### 需要补充信息

1. 点击“新调查”，选择“需要补充信息”，点击“运行演示”。
2. 查看要求补充当前版本与目标版本的追问，以及“将补充信息与原问题一起提交”的提示。
3. 展开检查器，核对终态“需要补充信息”；时间线只有决策与结束，没有搜索或读取。

演示始终按所选脚本播放，修改输入问题不会驱动真实推理，也不会自动续接为成功回答。
真实服务中的补充信息需要与原问题一起发起新调查。

### 证据不足

1. 点击“新调查”，选择“证据不足”，点击“运行演示”。
2. 查看“现有文档不足以支持这一结论”的提示；时间线包含一次搜索、一次读取，
   页面不发布带引用答案。
3. 展开检查器，点击“查看已读取证据”，核对保留的原创合成段落。

已读取证据与最终答案是不同状态：本场景有证据，但它不足以支撑问题所要求的承诺。

## 手动录制

录制由用户完成；仓库不新增录制任务、录制脚本或视频。可依次录制上述三条路径：
保留顶部合成数据标识，完整调查展示引用阅读与逐次调用，另外两条展示终态和检查器。
画面中的耗时、步骤和资料都是预设演示数据，不能用作真实模型速度或质量比较。

## 复验入口

场景实现位于 `frontend/src/lib/demo.ts`，交互位于 `frontend/src/App.tsx`；现有
`frontend/e2e/workbench.spec.ts` 已覆盖重复搜索、引用阅读、追问和证据不足。
浏览器回归使用合成场景并拦截 API，不需要真实服务或付费调用。

在一个终端保留上面的预览服务，另一个 PowerShell 终端从仓库根目录执行：

```powershell
$env:PLAYWRIGHT_BASE_URL = 'http://127.0.0.1:4173'
npm --prefix frontend run test:e2e -- e2e/workbench.spec.ts --grep 'repeated searches have separate details|terminal state: 需要补充信息|terminal state: 证据不足'
Remove-Item Env:PLAYWRIGHT_BASE_URL
```

本机配置使用已安装的 Chrome，CI 使用 Playwright Chromium。若本机没有 Chrome，
可按 `frontend/playwright.config.ts` 的浏览器配置准备相应环境。运行结果和截图在
`frontend/test-results/`，保持 Git 忽略；复验不录制视频。
