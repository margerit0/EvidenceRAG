## 现有行为必须保留

- 右侧检查器默认收起，只留箭头；桌面展开占用布局宽度，收起释放空间。
  1180px 及以下改为从右侧打开的模态抽屉。此处的“侧边栏”指右侧检查器，
  左侧导航轨道不在本轮范围内。
- 点击具体调用或桌面引用会打开对应详情；新事件与运行结束不主动展开检查器。
  折叠/展开保留调用、证据和标签选择。窄屏引用仍使用证据阅读层。
- 同类调用的上一次／下一次、第 X / N 次、跳到最新均保留；共享图节点的不同动作
  分别计数。新调用到达不改变手动选中的历史调用。
- 图节点表示动作类型，显示实际最新进度；时间线表示每一次调用，虚线标记当前查看。
  保留循环路径、状态色和文字，不用动画把执行过程改成固定线性流水线。
- 笔记本首屏输入/运行/停止、手机当前动作入口、引用选中、键盘焦点与阅读位置保持可用。
  默认合成演示、临时历史和引用验收边界准确可见。

## 动效与视觉目标

### 右侧检查器

- 展开、收起都应连续：面板位移/显隐、箭头反馈、相邻区域宽度变化保持协调。
  支持动画中反向操作，不闪烁、不突然重置位置、不等上一段动画结束才响应。
- 避免把文字整体缩放得模糊，或在展开过程中让文本反复换行、按钮被挤压。
  隐藏后的内容不能继续被键盘聚焦；抽屉的焦点限制、Esc、遮罩关闭和返回焦点要保留。
- 视觉方向是适度阻尼、自然减速、轻微层次变化；弹簧或缓动曲线是可选实现。
  不用夸张回弹、过长延迟或大面积模糊堆叠来表达质感。

### Agent graph

- 打磨节点、连线、当前执行态和调用选中态的层级、对比度与留白，兼顾浅深主题。
- 当前动作切换、工具往返、完成/异常的状态变化应清楚、克制，动画表达已有事件。
  不伪造未发生的调用，不为播放动画延迟真实状态展示；终态不残留“执行中”动效。
- 检查器改变画布尺寸时，图的定位与缩放应连续协调；全过程和最终状态均避免裁切。
  保留当前调用与缩放语义，画布尺寸不变时查看历史调用不自动重新缩放。
- 先复用已有 Motion、React Flow、Radix 和 CSS；只有明确改善效果时才增加依赖。
  “Apple 式”是观感参考，尚无指定页面、视频或精确曲线，不宣称像素级复刻。

当前桌面通过切换网格列与 `hidden` 收起，无完整过渡；窄屏只有 180ms 入场动画，
尚未完善退出与中途反向。箭头目前直接替换左右图标。这些是本轮可改进的基线。

上一轮发现图的测量完成信号没有就绪，导致画布变窄后仍按旧尺寸定位。
现已显式给节点 188×96 尺寸，并在 `viewportInitialized` 后按观察到的画布尺寸，
通过 `getViewportForBounds` / `setViewport` 适配。节点尺寸与布局样式应一致。
引入连续布局动画时，注意 ResizeObserver 与视图动画之间的重复计算、竞争和跳变；
不能仅删除边界检查或用重建整张图来掩盖问题。

## 验证与交付

- 实际查看普通动效：快速反复展开/收起、动画中反向、运行中切换调用、主题切换、
  连续到达事件、完成/异常、抽屉内引用阅读。检查节点和详情没有闪烁、裁切或遮挡。
- 视口：1440×1000、1366×768、1024×768、390×844；浅深主题均检查。
  用短录屏或连续帧辅助评估流畅度，静态截图只证明布局；不声称未经测量的稳定帧率。
- 检查 `prefers-reduced-motion`：可立即切换或轻量淡入，核心状态仍清楚。
  E2E 默认减少动效，应保留/补充普通动效下的折叠和画布回归。
- 执行前端单测、构建、格式与相关 E2E；修改后全套前端回归。
  提交时遵守 `CLAUDE.md` 门禁。不要新增只复述实现、不能发现行为回归的测试。
- 截图、录屏、性能记录保存在 `.research_tmp/frontend-motion/`（gitignored）。
  更新本文或 `docs/frontend.md`，报告实际改变、验证结果与尚存限制。
