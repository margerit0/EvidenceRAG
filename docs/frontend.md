# React 调查工作台

实现位于 `frontend/`，工作分支为 `feat/frontend-design`。用于作品演示与本地调试，
以问题、执行图、逐次调用和证据详情为主。默认运行原创合成演示，未连接任何模型。

新会话先读 [精简开发交接](frontend-next-session.md)，再按需要查阅本文或完整动效交接。

## 本地启动

需要 Node.js 22.12+ 和 npm。项目 `.npmrc` 固定兼容 peer 解析模式，避免 npm 10
解析可选 peer 时的 `edgesOut` 异常；依赖版本与完整性由 `package-lock.json` 锁定。
没有在项目中配置代理或镜像地址。

```powershell
cd frontend
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/workbench/`。Vite 将 `/api` 转发到
`http://127.0.0.1:8000`。先选“模拟演示”即可使用，不需要凭证、语料、Milvus 或后端。

生产构建：

```powershell
npm run build
```

从源码仓库启动现有 FastAPI 服务后，自动在 `/workbench/` 挂载 `frontend/dist`。
原 `/` 静态页面保留。构建目录未提交；部署应先构建，再启动后端。
嵌入式/安装包使用方式可向 `create_app(frontend_dir=...)` 显式传入构建目录。
前端配置不包含模型密钥，后端原有启用和预算边界继续生效。

### 选择调查模型

切到“连接服务”后，输入框底部、发送按钮左侧显示模型选择。本机已配置
**DeepSeek V4.1 Flash** 和 **GLM 5.3**；紧凑入口将前者显示为 DeepSeek，菜单保留完整名称。
菜单优先向上展开，沿用现有键盘操作、主题和动效。选择记忆到下次打开页面；点击
“开始调查”才会调用模型，运行中不能切换。答案旁、运行历史及检查器的“运行”页记录
该次使用的模型，更改选择不会改写已有记录。模拟演示不显示模型选择。

后端默认使用 `LLM_MODEL_NAME`，可重复传入 `--agent-model` 添加共用同一 `LLM_BASE_URL`
和 `LLM_API_KEY` 的模型。模型选择仅对文档调查生效，原 `/api/ask` 保持默认模型。
本机使用独立配置文件保留原 `.env`：

```powershell
.venv/Scripts/python.exe scripts/serve.py --enable-agent --env .research_tmp/frontend-model-selector-20261006/service.env --agent-model z-ai/glm-5.3 --generation-reasoning-effort low --generation-max-tokens 4096 --generation-timeout 90 --agent-max-seconds 600 --agent-generation-retries 1
```

本地配置默认 DeepSeek，附加选项为 GLM；新环境需自行提供服务端配置文件。
启动前确认 8000 端口空闲。浏览器不能指定任意服务地址或凭证。
旧版后端未提供模型列表时，前端仍按默认模型运行。

## 页面与状态

- 左侧问题及答案，中间执行图与时间线。右侧检查器默认收起，仅保留箭头；展开后显示
  步骤、证据和运行详情。桌面收起会释放布局宽度，所选调用、证据及详情标签保持不变。
- 点击具体调用或桌面答案引用会展开对应详情；新事件和运行结束不会主动展开检查器。
  折叠状态只存在本页面内存，刷新后恢复默认收起。
- 固定图表示可能的动作路径；时间线用独立调用编号记录重复搜索和多次决策。
  图节点展示该动作类型的最近一次调用，时间线可以查看更早的具体调用。
- 时间线与步骤标题按动作类型显示“第 N 次”，与模型轮次和全局调用序号分别标注。
  查看较早调用时，图节点以虚线及“正在查看第 N 次”同步标记选中调用；“最近”计数、
  节点执行状态和连线仍保留实际进度。检查器提供“上一次／下一次”和“第 X / N 次”，
  并保留较弱的“跳到最新”入口。三者都按相同动作类型导航；共享图节点的“校验答案”
  与“结束调查”仍分别计数，不互相跳转。完整执行顺序继续通过时间线查看。
- 第一项禁用“上一次”，最新项禁用“下一次”和“跳到最新”；仅一次调用时三者均禁用。
  新事件到达时更新总次数，保留手动选中的历史调用。相邻切换同步图、时间线和详情，
  不重建导航按钮，支持保持焦点并连续使用键盘浏览。
- 状态区分进行中、回答、追问、证据不足、预算耗尽、超时和停止。
  格式/引用校验通过不等于结论独立验收通过。
- 原创合成脚本不分析输入问题，模拟数据、事件和耗时始终明确标识。
- 浅深主题及模型选择偏好保存到本地；最近十次运行只存在页面内存，刷新即清空。
  不保存真实问答、语料或证据到 localStorage，也不上传外部观测平台。
- 仅已读取证据进入引用详情；搜索候选编号不冒充完整证据。
  完整段落与最终答案一起返回，当前不提供逐字答案流。
- 窄屏按问题、流程纵向排列；1180px 及以下的检查器从右侧展开为模态抽屉，箭头保持在
  屏幕右侧。抽屉支持箭头、Esc 和点击遮罩关闭，限制键盘焦点在抽屉内，关闭后恢复原
  焦点和阅读位置；动效响应 `prefers-reduced-motion`。
- 桌面较低视口将工作区高度约束在可视范围，问题/答案与检查器内部滚动，输入与运行/停止
  保持可见。`1366 × 768` 下时间线可完整显示至少三次调用，不缩小正文换取空间。
- 手机运行后在问题区域上方显示随滚动保留的进度条；“查看流程”会滚动并将焦点移到
  执行区域。窄屏运行提示使用“下方”，跳转响应减少动效设置。
- 1180px 及以下点击引用直接打开证据阅读层，手机端采用底部抽屉；
  桌面证据提供“展开阅读”。关闭后恢复触发元素焦点，不改变原阅读位置。
- 画布顶部固定展示当前动作与该动作调用次数；执行节点使用品牌底色，检查选中节点使用虚线外框。
  异常检查器突出中文终止原因，并提供已读取证据入口；“调用已返回”不代表调查成功。
- 图节点为选中调用说明预留固定高度；循环说明位于画布外。默认缩放与画布尺寸联动，
  折叠、展开或调整窗口时重新适配，画布尺寸不变时选择调用不改变缩放。节点精简重复
  英文标签，运行耗时合并到当前动作条。
- 桌面检查器以 420ms 减速过渡协调列宽、详情显隐和箭头旋转；详情按完整面板宽度
  排版后裁切展示，避免动画期间反复换行或缩放文字。关闭即设为不可交互，结束后隐藏。
  窄屏抽屉以 380ms 位移和遮罩淡入淡出进入/退出，中途反向保留当前面板与位置。
  退出中的箭头点击不会被延迟的外部关闭事件覆盖；重新展开后恢复模态焦点。
- 节点使用轻量边框、阴影与状态过渡；当前调用的入边显示短线段流动，调用结束即移除。
  查看态仍用独立虚线表示。紧凑图为工具往返安排独立弧线，并避开右侧检查器入口。
  画布尺寸观察器直接更新视图，不叠加第二段缩放动画；自动适配和“适应画布”都计入
  循环连线与查看外框。切换紧凑布局不重建 React Flow。
- 减少动效时，检查器即时切换、节点与连线停止装饰动画，执行状态及文字仍保留；
  打开抽屉期间修改系统动效偏好也会生效。
- “运行模式”与“演示场景”共用下拉动效：240ms 展开、160ms 收起，轻微位移和淡入淡出，
  箭头连续旋转，文字不缩放。向上弹出时位移方向随之调整；退出途中再次点击可从当前位置
  展开。保留键盘选择、Esc／外部点击取消、返回焦点及运行中禁用；减少动效时即时切换。
- 引用按钮点击区域为桌面 28px、手机 40px；当前引用与证据行使用一致的选中样式，
  并以 `aria-pressed` 表达选中状态。

## 组件与视觉

React + TypeScript + Vite；React Flow 展示流程，Lucide 提供图标，Motion 处理局部
状态切换。`components/ui.tsx` 采用 shadcn/ui 的 Button/CVA、Radix Tabs、Select、
Tooltip 和 Dialog 组合方式，并适配本项目语义色与尺寸；不依赖整套后台模板。
使用本地打包的 Inter Latin 字体及系统中文字体，不在运行时请求字体 CDN。

采用用户于 2026-10-05 确认的 **A · 冰川流线**：冰蓝曲面背景、通透玻璃窗口、
圆角分栏与冰白玻璃操作按钮；深色主题使用暮蓝底色和带细高光的灰蓝玻璃按钮。背景是项目原创 SVG，随 Vite 本地
打包，不请求图片或字体服务。主按钮及其悬停色、引用与证据编号选中色均使用独立主题变量，
保留文字对比度、描边和键盘焦点。`src/glacier.css` 集中管理主题颜色、材质和响应式外观，
`src/styles.css` 保留布局基础与交互状态。背景文件为 `src/assets/glacier.svg`。

顶栏横跨窗口，品牌与“新调查”位于顶栏；左侧保留调查、历史、主题和关于入口。
检查器仍默认收起。玻璃使用静态背景、半透明底色、细高光和轻阴影；模糊放在窗口的
独立背景层，避免让固定抽屉入口或手机进度条受包含块影响，也避免逐节点叠加滤镜。
菜单、抽屉和证据阅读层使用较实的玻璃底色；不支持背景模糊或启用减少透明度时，
文字面板回退为实色。成功、需关注和错误继续使用独立语义色与文字。
流程图及证据关系本身构成视觉主体，不加入持续运动的装饰背景。
组件库许可证随安装依赖提供；上游入口：
[shadcn/ui](https://ui.shadcn.com/)、[Radix](https://www.radix-ui.com/)、
[React Flow](https://reactflow.dev/)、[Motion](https://motion.dev/)。

## 实时接口

`GET /api/capabilities` 新增 `agent_streaming`。Agent 启用时，客户端可请求：

```http
POST /api/investigate/stream
Content-Type: application/json
Accept: text/event-stream

{"query":"需要调查的问题"}
```

一次 POST 只创建一次运行，不自动重试、不支持断线重连或跨页面历史查询。

| SSE 事件      | 含义                                                                                    |
| ------------- | --------------------------------------------------------------------------------------- |
| `run_started` | 本次请求的随机 `run_id`                                                                 |
| `progress`    | 连续 `seq`、独立 `invocation_id`、模型轮次、动作、开始/完成、相对时间、结果码和证据编号 |
| `result`      | `run_id` 与 `response`；后者复用 `/api/investigate` 的完整响应合同                      |
| `failure`     | 流基础设施故障的固定错误码，不含内部异常正文                                            |

HTTP 头发送前的未启用、参数错误和并发繁忙仍返回 503/422/429 JSON。
流开始后的模型或工具失败由 `result.response.status` 表示，不通过 HTTP 200 推断成功。
没有最终结果的断流显示“连接已中断”，不会自动重发可能产生费用的请求。

进度观察与模型使用的 `AgentEvent` 分离；不改变提示词、模型输入、预算、配置指纹或
既有 JSON 接口响应。事件只含公共动作、编号和计数，不包含模型原始输出或内部思考。
每请求队列上限 256；溢出请求合作取消并发送失败事件，不伪造完整轨迹。

停止会中断浏览器接收并请求后端合作取消。真实运行显示“已请求停止”，而不是宣称
供应商已停止；正在执行的阻塞调用仍受自身 timeout 约束，实际结束后才释放并发名额。
这不保证供应商停止计费。模拟播放则可以立即停止。

对于旧服务，客户端回退到 `/api/investigate`，仅展示完成后返回的记录。
旧 `elapsed_seconds` 是相对运行开始的时间，不能当成单个操作耗时。
